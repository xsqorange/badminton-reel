### ★★ R2 要达到「通过」需要什么（给最终交付说明用）

**一句话**：**R2 达不到「通过」不是因为阈值没调好，而是因为判定顺序错了 —— 必须改成「先合段、后判回合」；只调阈值和只补标注都不够。**

展开为三条，**缺一不可**：

1. **判定顺序改造（主因，纯算法）**：当前流程是「按瞬态先切碎成段 → 再逐段判是不是回合」。
   一段真回合被切成 3 段时，在 GT 的 50% 重叠判据下就是 **1 TP + 2 FP** —— 这正是 163 个 FP 的主要来源。
   改成「**先把碎片合并回回合，再对合并后的整组判回合性**」，FP 会大量转成 TP，precision 与 recall 同时上升。
   这是纯算法改造，参数放 profile 层，不涉及人工闸门。

2. **回合性判据要作用在「整组」而不是「碎片」上**：Chief 测到的 ROI 运动能量 真 0.662 / 负 0.330（区分度仅 2×）
   现在被用在碎片上 —— 一个回合的碎片单独看本来就不像回合，弱区分度在这里必然测不准。
   合并后整组的击球密度/节奏/运动曲线才有可比性。**这一步做完，才轮到再扫一轮 `shot_gate_percentile` / `shot_gate_window` / `rally_merge_gap` 参数。**

3. **补齐「检测器漏检」的候选发现**：人工精标的 note 里反复写着「检测器漏检」「检测器切成两段+漏检」——
   这些回合**根本没进入候选集**，recall 上不去不是调参能解决的，需要候选发现环节能覆盖到
   「弱起手 + 弱收尾 + 中间漏一两拍」的回合（当前漏检机制见 `detect_hits` 的漏检 → 空档 >1.6s → 聚类断开）。

**而以下两件事不解决 R2**：

- **补更多人工标注**：只提升指标的**可信度**（减少样本噪声），不提升指标本身。现有 157 条人工精标已足够说明问题。
- **继续调阈值**：Chief 已实测 ROI 运动对真假回合区分度只有 2×，在碎片粒度上再怎么调也压不下这 163 个 FP。

**因此给用户的最终口径建议（两选一，必须明写）**：

- **要么做 ①②③**（算法改造，非人工闸门），目标 F1 ≥ 0.7、precision ≥ 0.6、recall ≥ 0.8；
- **要么接受当前值并记成已知上限**：在「全馆混音 + 固定单机位 + 4~5 片场地同时在打」这个输入条件下，
  **音频单通道方案的 precision 天花板就在 0.39 附近**；要突破必须换输入（分路音频/多麦阵列）或换模态（球轨迹视觉跟踪），
  那是另一个量级的工程。**当前状态不能被表述成「还能更好但没做」，也不应被表述成「做错了」——
  它是当前输入条件下的实测上限，用户要「正确识别每个羽毛球回合」这一条应据此如实说明差距与路径。**
