## 三、口径裁定（本次返工必须遵守的定义）

| 口径 | 定义 |
|---|---|
| **A 回合** | 一个回合 = **主球场**内从发球到得分的一次连续对打。背景场对打、换人走动、单人挥拍练习、捡球**都不算回合**。 |
| **B 拍数** | 一次拍数 = **主球场内**的一次击球。**拍数不得直接取自混合音频瞬态数**；必须限定主球场，且计数方法与 `detect_hits` 的聚类参数**解耦**（解耦这一步执行员 15:05 已做对，保留）。 |
| **C 长回合** | 主球场内、**合并后为单一回合**、拍数 ≥ 30。阈值仍是配置项 `select.long_rally_shots = 30`，**不许动**。 |
| **D 真值** | GT 必须是**人工目视**产物（人工判定是否回合 + 人工计拍或人工确认区间）。脚本产物只能进 `eval/candidates/` 或 `eval/independent/`。 |
| **E 负样本** | 非回合区间必须显式落为**负样本集**，用于测 precision 与长回合排除率。 |
| **F id 稳定** | GT 的 id 不随集合重排变化；被作废的 id 保留墓碑条目（`deprecated: true`），避免旧报告/baseline 按 id 引用时错位。 |
| **G 数字口径** | 报告里每个指标必须同时给 **(n=样本数, 复算命令, GT 文件清单+哈希)**。召回率不带 n 一律不采信（沿用踩坑 3.13）。 |

**口径修正后长回合条数变多变少都可接受**——只要口径写清楚、不自证。用户要的"≥30 拍"指的就是**主球场**上的 30 拍对打；背景场的击球从来不属于这个口径，把它们计进来是度量错误，不是"更多高光"。
